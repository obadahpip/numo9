# Numo9 design system (`@numo9/ui`)

One component library for every Numo9 screen (deliverable A-10). Xero runs two UI generations,
three template systems and mixed date formats; Numo9 screens are assembled only from these
components, so a bill editor, an invoice editor and a journal look and behave the same.

## Rules every screen follows

| #   | Rule                                                                                            | How it is enforced                         |
| --- | ----------------------------------------------------------------------------------------------- | ------------------------------------------ |
| 1   | Build screens from `@numo9/ui` only — no module-specific grid, picker, date or empty state      | Review (CODEOWNERS on `packages/ui`)       |
| 2   | Colours, type, spacing, radius and elevation come from the tokens, never literal values         | `tokens:check`, contrast check (≥ 4.5 : 1) |
| 3   | Every visible string is an i18n message (en-CA now, fr-CA from day one)                         | `formatjs/no-literal-string-in-jsx`        |
| 4   | Canadian English: organisation, cheque, Province, Postal code, GST/HST, vacation pay            | Glossary lint (gap-31, gap-38)             |
| 5   | No promotional or announcement banners in work screens; notices go to the notification centre   | `numo9/no-work-screen-banners` (gap-12)    |
| 6   | Keyboard operable, visible focus, 44 px targets, 0 serious axe violations                       | Vitest + axe, browser a11y suite (gap-60)  |
| 7   | One date and money format per locale: `26 Oct 2026`, `$1,234.56` / `26 oct. 2026`, `1 234,56 $` | `formatDate`, `formatMoney`                |
| 8   | Logical CSS properties (`ms-`, `pe-`, `start-`) so layouts are RTL-ready                        | Review                                     |

## Using the library

```tsx
import "@numo9/ui/styles.css";
import { Button, DataGrid, formatMoney } from "@numo9/ui";
```

Components hold no text of their own: labels arrive through props from the app's message
catalogue (`useFormatMessage` in the web app).
