# Forms and pickers

## Form kit

React Hook Form + Zod field wrappers (A-10-T07): inline errors, an error summary at the top with
links to each field, focus moved to the first error, a sticky save bar and an unsaved-changes
guard.

<Canvas of={Forms.GeneralSettings} />

<DoDont>
  <Do>
    <p>Validate on submit, then live for fields that already have an error.</p>
    <p>Error text that names the field and the fix: "Postal code should look like 'M5V 2T6'."</p>
    <p>A sticky save bar with a verb ("Save settings") on long settings pages; ⌘/Ctrl+S saves.</p>
  </Do>
  <Dont>
    <p>Red outline without a message, or errors only in a toast.</p>
    <p>
      Asking for everything up front — ask for BN, fiscal year end and registrations in context

  </Dont>
</DoDont>

## Pickers

DatePicker (with shortcuts +7, +14, end of month …), Province picker, Postal code input,
Currency input, Account picker (filtered by type and side) and Contact picker (A-10-T09).

<Canvas of={Pickers.English} />

<DoDont>
  <Do>
